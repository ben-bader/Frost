# Asset provenance

Every visual and textual element in `docs/assets/` traces to a real file in
this repository or to a captured run of the framework. Nothing is invented.
Regenerate with `pnpm docs:assets` (`node scripts/build-readme-assets.mjs`);
validate with `pnpm docs:check-assets` (`node scripts/check-assets.mjs`).

## Logo

The project ships **raster** logos only — there is no SVG logo in the repo.

| Source file | Size | Used as |
|---|---|---|
| `examples/starter/public/frost-mark.png` | 334×267, 97,758 B | mark element of the banner/social lockup and the README footer |
| `examples/starter/public/frost-wordmark.png` | 755×139, 114,384 B | wordmark element of the banner/social lockup |

The SVGs cannot embed the originals directly (they would exceed the 150 KB
per-file budget), so `scripts/logo-src/` holds Lanczos-downscaled
derivatives at ~2× their maximum display size. Provenance (source path,
SHA-256 of source and embedded file, dimensions, transform) is recorded in
`scripts/logo-src/manifest.json`; `check-assets.mjs` fails if any embedded
raster does not hash-match that manifest. The logo is never recolored,
redrawn, or restretched — `<image>` elements scale the real pixels
proportionally (`preserveAspectRatio="xMidYMid meet"`). On light variants
the lockup sits on a `#0a1c1e` panel so the real artwork is shown unchanged.

| Terminal `ERROR` block lines (`code`, `at`, `route`, `runtime`) | `packages/core/src/diagnostics.ts` `formatErrorReportTerminal` — badge is the only colored element; all other lines render in the default terminal foreground, which the SVG reproduces |

`allowed-strings.json` is generated by the build script; `check-assets.mjs`
extracts every `<text>`/`<tspan>` string from the SVGs and fails on anything
not in that list.

## Palette

Mint `#10e8c8`, deep teal `#0a1c1e`, teal `#143638`, muted `#b9c9c6`,
dim `#6f9390`, danger `#ff4d5e`, warning `#ffb86b` — the brand palette
specified for Frost assets. Semantic colors reused from real sources:
overlay card/border/accent/button colors and the terminal `ERROR` badge
(`white on #ff4d5e`, matching `\x1b[41m\x1b[37m`) come from
`dev-client.ts` / `diagnostics.ts`.

## Reproducing the capture

`audit-output/` is git-excluded. To reproduce the overlay capture:

```bash
node audit-output/setup-overlay-app.mjs   # copies starter to OS temp, adds a broken loader
node audit-output/capture-overlay.mjs     # starts dev server, curls /hello/world, saves overlay-capture.json
```

The temporary app is deleted afterwards; see `audit-output/OVERLAY_SPEC.md`
for the element-by-element mapping.
