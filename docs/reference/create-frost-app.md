# create-frost-app

> The scaffolding CLI behind `npm create frost-app`. Source: `packages/create-frost-app`.

**Last verified against v0.1.1.**

## Usage

```bash
npm create frost-app@latest my-app
# or
npx create-frost-app@latest my-app
```

Creates `my-app/` in the current directory, installs dependencies, and prints next steps.

## Templates

| `--template` | Contents |
|---|---|
| `starter` (default) | Full starter generated from `examples/starter`: Tailwind v4, Space Grotesk/Mono, bento components, `/playground`, contract-validated `/hello/[name]`, API routes, middleware, error/not-found pages |
| `minimal` | Small single-page app — fastest path to a running Frost page |

```bash
npm create frost-app@latest my-app -- --template minimal
```

Unknown template names fail with a clear error listing the valid choices.

## What the scaffold produces

- `package.json` — name `my-app`, `workspace:`/`file:` ranges rewritten to published `^0.1.1` ranges, scripts `dev`/`build`/`start`/`typecheck`
- `frost.config.ts`, `tsconfig.json` (standalone — no monorepo references)
- `src/app/` routes, `src/api/` endpoints, `src/components/`, `src/styles/app.css`, `src/config/`, `src/data/`
- `postcss.config.mjs`, `public/` assets, `_gitignore` → `.gitignore`

The default template is generated by `scripts/sync-template.mjs` from `examples/starter` and drift-checked by `pnpm check:template` — the published tarball always matches the repo's starter.

## Flags

| Flag | Description |
|---|---|
| `--template <name>` | `starter` (default) or `minimal`; unknown names error with valid choices |
| `--pm <pm>` | Package manager for install: `pnpm`, `npm`, `yarn`, `bun` |
| `--install` / `--no-install` | Run (or skip) dependency installation — install is the default |
| `--no-git` | Skip `git init` |
| `--no-color` | Disable ANSI colors (also `NO_COLOR`) |
| `--no-emoji` | Remove emoji (also `FROST_NO_EMOJI=1`) |
| `--ascii` | ASCII symbols instead of Unicode (also `FROST_ASCII=1`) |
| `--help`, `-h` | Usage |
| `--version`, `-v` | Version |

Source: `packages/create-frost-app/bin.js`.

## Terminal output

The scaffolder prints a branded header (`create-frost-app <version>`), a
rail card with the real project name, template, and detected/supplied
package manager, spinner-driven step lines (template copy, `git init`,
dependency install with real elapsed seconds), and a rounded **Next
steps** box with the correct commands for the detected package manager.
`--no-install` replaces the install step with a dim `Skipped install` line
and adds the install command to Next steps. A failed install prints the
last 20 lines of the captured package-manager log (dimmed) plus the manual
retry command and exits non-zero.

The same fallback rules as the `frost` CLI apply: `NO_COLOR`/`--no-color`,
`FORCE_COLOR`, non-TTY single-line steps, `--no-emoji`/`FROST_NO_EMOJI`,
`--ascii`/`FROST_ASCII`/`TERM=dumb`/non-UTF-8/legacy-console ASCII mode, and
sub-60-column narrowing. Review all frames with `pnpm cli:preview`.
