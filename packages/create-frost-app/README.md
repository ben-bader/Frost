# create-frost-app

Scaffolds a new [Frost](https://frostjs.dev) application.

```bash
npm create frost-app@latest my-app
```

Templates:

- `starter` (default) — the full showcase app from `examples/starter`,
  generated by `scripts/sync-template.mjs` at pack time.
- `minimal` — a tiny hand-written app (`--template minimal`).

Other flags: `--no-install`, `--no-git`, `--pm <pnpm|npm|yarn|bun>`,
`--help`, `--version`.
